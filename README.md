# Иконка приложения

Восемь вариантов, каждый показан в трёх размерах (84 / 48 / 32 px), на светлой и
тёмной подложке и в монохромном виде — последнее нужно темам Android 13+.

Открыть галерею: `design/icons.html` в браузере. Файл самодостаточный, внешних
зависимостей нет.

| Вариант | Форма | Подложка | Настроение |
|---|---|---|---|
| **Волна** | синусоида | бирюза | спокойное, своё имя приложения |
| **Нота** | нота | голубой | сразу понятно, что это музыка |
| **Рhythm** → **Ритм** | три полоски | песочный | читается даже в мелком размере |
| **Круг** | виниловая пластинка | зелёный | самое спокойное |
| **Играть** | кнопка в рамке | сиреневый | самое узнаваемое |
| **Капля** | капля | голубой | хорошо в крупном размере |
| **Сфера** | круг с бликом | терракотовый | объёмное и спокойное |
| **Дуга** | две дуги | зелёный | минималистичное |

Сейчас в приложении стоит **Волна**: она совпадает с бирюзовой палитрой темы и
мягче остальных — под стать названию.

## Как применить другой вариант

1. Открыть `design/icons.html`, выбрать нужный.
2. Взять его `art` из блока `<script>` — там одна строка SVG с `FILL` вместо цвета.
3. Вписать в `app/src/main/res/drawable/ic_launcher_foreground.xml`, заменив
   `FILL` на цвет из `light.fg`.
4. Поменять `android:background` в `mipmap-anydpi-v26/ic_launcher.xml` и
   `ic_launcher_round.xml`, если нужен свой фон вместо `@color/ic_launcher_background`.

Цвета подложки лежат рядом с каждой фигурой: `light.bg` и `dark.bg`.
Для Android 13+ есть третий слой — `monochrome`, он рисуется цветом темы,
поэтому фон для него не нужен.

# Volna

Мягкий музыкальный плеер для Android. Ищет треки в **YouTube Music** и стримит
аудио напрямую — без загрузки файла и без рекламы.

## Что умеет

- **Поиск в YouTube Music** — официальные треки с исполнителем и альбомом уже
  в подписи, поэтому в выдаче нет часовых миксов и стримов.
- **Прямой стриминг** — ExoPlayer читает аудиопоток по HTTP с докачкой,
  ничего не скачивая целиком.
- **Переподключение** — ссылка YouTube живёт несколько часов и привязана к IP,
  поэтому при 403 приложение само берёт её заново.
- **Очередь** — следующие треки подтягиваются во время игры, чтобы переключение
  не ждало сети.
- **Альбомы и исполнители** — каталог из открытого API iTunes.
- **Похожие треки** — по текущему, через рекомендации YouTube.
- **Скачивание** — по кнопке, если нужен файл на устройство.
- **Тёмная и светлая тема**, Material 3 Expressive.
- **Русский и английский** языки интерфейса.

## Как это работает

Поиск идёт через внутренний API InnerTube — тот же, что у официального
приложения, но без ключей и капчи:

```
POST https://music.youtube.com/youtubei/v1/search   клиент WEB_REMIX
```

YouTube Music размечает каждый элемент типом (`Композиция`, `Видео`, `Альбом`,
`Плейлист`, `Подкаст`) и отдаёт `videoId` прямо в `playlistItemData`. Поэтому
официальные треки отделяются от всего остального одной проверкой типа — в
обычном поиске YouTube такой разметки нет, и туда попадают клипы и миксы.

Сам аудиопоток отдаётся только обычному клиенту InnerTube, поэтому получение
ссылки идёт отдельно — на `www.youtube.com`, клиентами `ANDROID`,
`ANDROID_VR`, `IOS` по очереди.

Если YouTube Music ничего не нашёл — например, трека нет в его каталоге —
поиск проваливается в обычный YouTube, и результаты объединяются.

## Сборка

Нужен JDK 17 и Android SDK (compileSdk 35).

```bash
./gradlew :app:assembleDebug          # APK для отладки
./gradlew :app:assembleRelease        # релизный APK (без подписи)
./gradlew :app:testDebugUnitTest      # юнит-тесты
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Структура

```
app/                      приложение (Compose, Material 3)
  search/                 InnerTube: YouTubeMusicSearch + запасной YouTubeSearch
  stream/                 получение и проверка ссылки на аудио
  player/                 MediaSessionService на ExoPlayer
  catalog/                альбомы и исполнители через iTunes
ytdl/                     библиотека получения потока (чистая Java, без зависимостей)
design/                   варианты иконки
```

Пакеты: `com.volna.player` — приложение, `com.ytdl.core` — библиотека.

## Тесты

Парсер ответа InnerTube покрыт юнит-тестами на настоящих ответах API —
фикстуры лежат в `app/src/test/resources`. Это нужно потому, что YouTube
периодически меняет разметку выдачи, и без них смена вёрстки выглядела бы
просто как «поиск перестал находить».

## Оговорка

Приложение не скачивает музыку: оно стримит аудиопоток, как это делает любой
сетевой плеер. Файлы сохраняются только по явному нажатию кнопки «Скачать».
Использование — на свой страх и риск, в соответствии с
[условиями YouTube](https://www.youtube.com/t/terms).
