## Що вміє

- **Пошук у YouTube Music** — в офіційних треках виконавець і альбом уже в
  підписі, тож у видачі не плутаються погодинні мікси та стрими.
- **Запасний пошук по відео** — якщо треку немає в каталозі YouTube Music,
  застосунок скаже про це й знайде його в звичайному YouTube, а не увімкне
  щось інше мовчки.
- **Прямий стриминг** — ExoPlayer читає аудіопотік по HTTP з докачкою, нічого
  не завантажуючи цілком.
- **Перепідключення** — посилання YouTube прив'язане до IP і старіє, тому при
  403 застосунок сам бере його знову.
- **Черга** — наступні треки підтягуються під час гри, перемикання не чекає
  мережу.
- **Альбоми та виконавці** — каталог із відкритого API iTunes.
- **Схожі треки** — радіо на рекомендаціях YouTube Music, а не звичайного
  YouTube.
- **Медіатека** — «подобається» та власні плейлисти з перестановкою, усе
  зберігається на пристрої.
- **Слухати все за виконавцем** — один перемішаний набір з усіх його альбомів.
- **Офлайн** — завантаження в спільну теку `Music/Volna`, грається без мережі.
- **Темна й світла тема**, Material 3 Expressive.
- **Вісім мов** — англійська, російська, українська, білоруська, французька,
  іспанська, китайська, арабська.

## Як це працює

Пошук іде через внутрішній API InnerTube — той самий, що в офіційному застосунку,
але без ключів і капчі:

```
POST https://music.youtube.com/youtubei/v1/search   клієнт WEB_REMIX
```

YouTube Music позначає кожен елемент типом (`Song`, `Video`, `Album`,
`Playlist`, `Podcast`) і віддає `videoId` просто в `playlistItemData`. Тому
офіційні треки відокремлюються від решти однією перевіркою типу — у звичайному
пошуку YouTube такої розмітки немає, і туди потрапляють кліпи та ремікси.

Підбір трека віддає перевагу виконавцю, а не назві. Без цього кліп фана
«Атлантида [КЛІП]» переміг би справжню «Атлантиду»: назва збігається ідеально,
а виконавець — ні. Переробки (`slowed`, `reverb`, `remix`, `cover`, `nightcore`)
відсіюються, якщо ремікс не запитано на ім'я.

Саме аудіопотік віддається лише звичайним клієнтам InnerTube, тому отримання
посилання йде окремо — на `www.youtube.com`, клієнтами `ANDROID`, `ANDROID_VR`
та `IOS` по черзі.

## Збірка

Потрібні JDK 17 та Android SDK (compileSdk 35).

```bash
./gradlew :app:assembleDebug          # APK для налагодження
./gradlew :app:assembleRelease        # релізний APK
./gradlew :app:testDebugUnitTest      # модульні тести
```

Кожна збірка релізу копіюється в `dist/`, тому збірки не затирають одна одну:

```
dist/volna-1.0.5-release.apk             звичайна збірка, com.volna.player
dist/volna-1.0.5-FOR_ISLAND-<пакет>.apk варіант для динамічного острова, див. нижче
```

Не використовуй `app/build/outputs/apk/release`: це службова тека, яку кожна
збірка перезаписує, тож файл, який там лежить, може бути не тим варіантом,
який ти збирався встановити.

### Підпис релізу

Релізний ключ лежить поруч із проєктом, але не потрапляє в git — натомість його
позначає `keystore.properties`:

```properties
storeFile=volna-release.jks
storePassword=<пароль сховища>
keyAlias=volna
keyPassword=<пароль ключа>
```

Обидва файли в `.gitignore`. Створити свій ключ:

```bash
keytool -genkeypair -v -keystore volna-release.jks \
  -keyalg RSA -keysize 4096 -validity 10000 -alias volna
```

Якщо `keystore.properties` немає, збірка не падає, а лишається непідписаною —
тож її можна запустити на чистій машині, не маючи ключа.

Підпис увімкнено зі схемами v1, v2 і v3: v2 покриває Android 7+, v3 потрібен
для оновлення поверх уже встановленого на Android 11+.

> **Ключ у цій збірці тестовий, пароль `volna-release` відомий за замовчуванням.**
> Заміни його своїм і тримай у таємниці: втрачений ключ не дасть випустити
> оновлення під тією самою особою, а скомпрометований дозволить комусь підписувати
> збірки від твого імені.

## Структура

```
app/                      застосунок (Compose, Material 3)
  search/                 InnerTube: YouTubeMusicSearch + запасний YouTubeSearch
  stream/                 отримання та перевірка посилання на аудіо
  player/                 MediaSessionService на ExoPlayer
  catalog/                альбоми та виконавці через iTunes
  library/                «подобається» та плейлисти
  download/               офлайн-завантаження
ytdl/                     бібліотека отримання потоку (чиста Java, без залежностей)
design/                   варіанти піктограми
```

Пакети: `com.volna.player` — застосунок, `com.ytdl.core` — бібліотека.

## Тести

Парсер відповіді InnerTube покрито модульними тестами на справжніх відповідях
API — фікстури лежать у `app/src/test/resources`. Це потрібно, бо YouTube
періодично змінює розмітку видачі, і без них зміна верстки виглядала б просто як
«пошук перестав знаходити».

## Варіант FOR_ISLAND

Деякі оболонки телефонів (vivo/OriginOS та інші китайські) показують
розгорнутий плаваючий програвач лише для застосунків із зашитого білого списку.
Якщо твій телефон із таких, допомагає збірка з іншим іменем пакета:

```bash
./gradlew assembleRelease -PforIslandPackage=com.tencent.qqmusic
```

Змінюється **лише `applicationId`** — ім'я пакета на пристрої. Код,
`namespace` і все інше лишається колишнім, тож звичайна збірка не зачіпається.

Що варто пам'ятати:

- Це костиль під конкретні оболонки, а не універсальне рішення.
- Такий APK посідає чуже ім'я пакета, тому встановити його разом з оригіналом
  не можна — доведеться видалити оригінал.
- Мітка `FOR_ISLAND` і причина потрапляють у `versionName`, щоб варіант було
  видно в списку пакетів.
- Основний пакет — `com.volna.player`, і він не змінюється.

## Застереження

Застосунок не завантажує музику: він стримить аудіопотік, як будь-який мережевий
програвач. Файли записуються лише за явного натискання кнопки «Завантажити».
Використання — на власний ризик, відповідно до
[умов YouTube](https://www.youtube.com/t/terms).
