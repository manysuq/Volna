# Иконка приложения

Восемь вариантов, каждый показан в трёх размерах (84 / 48 / 32 px), на светлой и
тёмной подложке и в монохромном виде — последнее нужно темам Android 13+.

Открыть галерею: `icons.html` в браузере. Файл самодостаточный, внешних
зависимостей нет.

| Вариант | Форма | Подложка | Настроение |
|---|---|---|---|
| **Волна** | синусоида | бирюза | спокойное, своё имя приложения |
| **Нота** | нота | голубой | сразу понятно, что это музыка |
| **Ритм** | три полоски | песочный | читается даже в мелком размере |
| **Круг** | виниловая пластинка | зелёный | самое спокойное |
| **Играть** | кнопка в рамке | сиреневый | самое узнаваемое |
| **Капля** | капля | голубой | хорошо в крупном размере |
| **Сфера** | круг с бликом | терракотовый | объёмное и спокойное |
| **Дуга** | две дуги | зелёный | минималистичное |

Выбрана **Дуга** на тёмной подложке: две дуги `#94E2BE` по градиенту
`#0F3A2E → #0A221A`. Минималистично, спокойно и хорошо читается в любом размере.

## Что уже в проекте

- `app/src/main/res/drawable/ic_launcher_foreground.xml` — контуры дуг (vector)
- `app/src/main/res/drawable/ic_launcher_background.xml` — градиентная подложка
- `app/src/main/res/mipmap-anydpi-v26/` — adaptive-иконка, включая слой
  `monochrome` для тем Android 13+
- `app/src/main/res/mipmap-*dpi/` — растровые иконки для Android 7.x
  (`minSdk = 24`, а adaptive-иконки появились только в Android 8.0)
- `design/render.html` — исходник, из которого рендерятся PNG

Фигура сдвинута на 2 единицы вниз от математического центра: у купола центр
тяжести выше геометрического, и без сдвига дуги висят под потолком.

## Как поменять на другой вариант

1. Открыть `icons.html`, выбрать нужный.
2. Взять его `art` из блока `<script>` — там одна строка SVG с `FILL` вместо цвета.
3. Вписать в `ic_launcher_foreground.xml`, заменив `FILL` на цвет из `light.fg`.
4. Поменять цвета градиента в `ic_launcher_background.xml`.
5. Перерисовать PNG: отредактировать `render.html` и заново выполнить рендер
   в `mipmap-*dpi` (нужен chromium; команды — в истории репозитория).

Цвета подложки лежат рядом с каждой фигурой: `light.bg` и `dark.bg`.
