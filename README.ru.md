# Volna

**VIBECODED**

Мягкий музыкальный плеер для Android. Ищет треки в **YouTube Music** и стримит
аудио напрямую — без загрузки файла, без рекламы и без аккаунта.

## Что умеет

- **Поиск в YouTube Music** — у официальных треков исполнитель и альбом уже в
  подписи, поэтому в выдаче не мешаются часовые миксы и стримы.
- **Запасной поиск по видео** — если трека нет в каталоге YouTube Music,
  приложение скажет об этом и найдёт его в обычном YouTube, а не включит что-то
  другое молча.
- **Прямой стриминг** — ExoPlayer читает аудиопоток по HTTP с докачкой, ничего
  не скачивая целиком.
- **Переподключение** — ссылка YouTube привязана к IP и стареет, поэтому при 403
  приложение само берёт её заново.
- **Очередь** — следующие треки подтягиваются во время игры, переключение не
  ждёт сеть.
- **Альбомы и исполнители** — каталог из открытого API iTunes.
- **Похожие треки** — радио на рекомендациях YouTube Music, а не обычного
  YouTube.
- **Медиатека** — «нравится» и свои плейлисты с перестановкой, всё хранится на
  устройстве.
- **Слушать всё по исполнителю** — один перемешанный набор по всем его альбомам.
- **Офлайн** — скачивание в общую папку `Music/Volna`, играется без сети.
- **Тёмная и светлая тема**, Material 3 Expressive.
- **Восемь языков** — английский, русский, украинский, белорусский, французский,
  испанский, китайский, арабский.

## Как это работает

Поиск идёт через внутренний API InnerTube — тот же, что у официального
приложения, но без ключей и капчи:

```
POST https://music.youtube.com/youtubei/v1/search   клиент WEB_REMIX
```

YouTube Music размечает каждый элемент типом (`Композиция`, `Видео`, `Альбом`,
`Плейлист`, `Подкаст`) и отдаёт `videoId` прямо в `playlistItemData`. Поэтому
официальные треки отделяются от всего остального одной проверкой типа — в
обычном поиске YouTube такой разметки нет, и туда попадают клипы и миксы.

Подбор трека отдаёт предпочтение исполнителю, а не названию. Без этого клип
фаната «Атлантида [КЛИП]» выигрывал бы у настоящей «Атлантиды»: название
совпадает идеально, а исполнитель — нет. Переделки (`slowed`, `reverb`,
`remix`, `cover`, `nightcore`) отсеиваются, если ремикс не запрошен по имени.

Сам аудиопоток отдаётся только обычным клиентам InnerTube, поэтому получение
ссылки идёт отдельно — на `www.youtube.com`, клиентами `ANDROID`, `ANDROID_VR`
и `IOS` по очереди.

## Сборка

Нужен JDK 17 и Android SDK (compileSdk 35).

```bash
./gradlew :app:assembleDebug          # APK для отладки
./gradlew :app:assembleRelease        # релизный APK
./gradlew :app:testDebugUnitTest      # юнит-тесты
```

Каждая сборка релиза копируется в `dist/`, поэтому сборки не затирают друг друга:

```
dist/volna-1.0-release.apk             обычная сборка, com.volna.player
dist/volna-1.0-FOR_ISLAND-<пакет>.apk вариант для динамического острова, см. ниже
```

Папку `app/build/outputs/apk/release` не используй: она служебная и
перезаписывается каждой сборкой, так что лежащий там файл может оказаться не
тем вариантом, который ты собирался ставить.

### Подпись релиза

Релизный ключ лежит рядом с проектом, но в git не попадает — вместо него
используется `keystore.properties`:

```properties
storeFile=volna-release.jks
storePassword=<пароль хранилища>
keyAlias=volna
keyPassword=<пароль ключа>
```

Оба файла в `.gitignore`. Создать свой ключ:

```bash
keytool -genkeypair -v -keystore volna-release.jks \
  -keyalg RSA -keysize 4096 -validity 10000 -alias volna
```

Если `keystore.properties` нет, сборка не падает, а остаётся неподписанной —
так её можно запустить на чистой машине, не имея ключа.

Подпись включает схемы v1, v2 и v3: v2 покрывает Android 7+, v3 нужен для
обновления поверх уже установленного на Android 11+.

> **Ключ в этой сборке тестовый, пароль `volna-release` известен по умолчанию.**
> Замените его своим и храните в тайне: потерянный ключ не даст выпустить
> обновление под тем же именем, а скомпрометированный позволит кому-то подписывать
> сборки как вам.

## Структура

```
app/                      приложение (Compose, Material 3)
  search/                 InnerTube: YouTubeMusicSearch + запасной YouTubeSearch
  stream/                 получение и проверка ссылки на аудио
  player/                 MediaSessionService на ExoPlayer
  catalog/                альбомы и исполнители через iTunes
  library/                «нравится» и плейлисты
  download/               офлайн-загрузки в общую папку Music
ytdl/                     библиотека получения потока (чистая Java, без зависимостей)
design/                   варианты иконки
```

Пакеты: `com.volna.player` — приложение, `com.ytdl.core` — библиотека.

## Тесты

Парсер ответа InnerTube покрыт юнит-тестами на настоящих ответах API — фикстуры
лежат в `app/src/test/resources`. Это нужно потому, что YouTube периодически
меняет разметку выдачи, и без них смена вёрстки выглядела бы просто как «поиск
перестал находить».

## Вариант FOR_ISLAND

Некоторые оболочки телефонов (vivo/OriginOS и другие китайские) показывают
развёрнутый плавающий плеер только для приложений из захардкоженного белого
списка. Если твой телефон из таких, помогает сборка с другим именем пакета:

```bash
./gradlew assembleRelease -PforIslandPackage=com.tencent.qqmusic
```

Меняется **только `applicationId`** — имя пакета на устройстве. Код,
`namespace` и всё остальное остаётся прежним, поэтому обычная сборка не
затрагивается.

Что нужно помнить:

- Это костыль под конкретные оболочки, а не универсальное решение.
- Такой APK занимает чужое имя пакета, поэтому установить его вместе с
  оригиналом нельзя — придётся удалить оригинал.
- Метка `FOR_ISLAND` и причина попадают в `versionName`, чтобы вариант было видно
  в списке пакетов.
- Основной пакет — `com.volna.player`, и он не меняется.

## Оговорка

Приложение не скачивает музыку: оно стримит аудиопоток, как любой сетевой
плеер. Файлы сохраняются только по явному нажатию кнопки «Скачать».
Использование — на свой страх и риск, в соответствии с
[условиями YouTube](https://www.youtube.com/t/terms).
